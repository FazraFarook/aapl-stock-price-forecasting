# Time Series Forecasting of Apple Inc. Stock Prices

## Overview

This project analyzes daily AAPL stock prices from 2020–2026 and compares ARIMA and ARIMAX models for forecasting stock log returns and reconstructing price forecasts.

## Dataset

* Source: Yahoo Finance (`yfinance`)
* Ticker: AAPL
* Frequency: Daily

**Note:** A local copy of the dataset (`aapl_stock_data.csv`) is included to ensure reproducibility, since data retrieved from Yahoo Finance may vary slightly over time.

## Methods

* Data preprocessing
* Exploratory data analysis
* ARIMA modelling
* ARIMAX modelling
* Forecast evaluation
